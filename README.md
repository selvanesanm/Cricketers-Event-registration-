# 🏏 Cricketers Meet Up

Cricketers Meet Up is a simple and responsive front-end website designed for a cricket fan event. The website provides event information, featured cricketers, event registration, login/register functionality, and a cricket jersey collection.

## 📌 Project Overview

The main purpose of this project is to create an attractive and user-friendly website for a cricket meet-up event.

Users can explore event details, view featured cricketers, check the event schedule, register for the event, and browse cricket jerseys.

This project is developed using basic front-end technologies:

- HTML
- CSS
- JavaScript

## ✨ Features

- 🏠 Attractive home page
- 🏏 Featured cricketers section
- 📅 Event schedule
- 🎥 Event videos
- 🔐 Login and registration page
- 📝 Event registration form
- 🎟️ Multiple event pass options
- 👕 Cricket jersey collection
- 🔎 Jersey search and filtering
- 📏 Jersey size selection
- 📱 Responsive user interface
- ✅ Basic JavaScript form validation

## 📄 Website Pages

### 🏠 Home Page

The home page provides an overview of the Cricketers Meet Up event.

It includes:

- Event introduction
- Featured cricketers
- Event videos
- What to expect
- Event schedule
- Social media links

### 🔐 Login / Register Page

The authentication page provides options for users to:

- Login
- Create an account

The registration form includes:

- Full Name
- Email
- Password

### 📝 Event Registration Page

Users can register for the Cricketers Meet Up event by providing their details.

The registration form includes:

- Full Name
- Email
- Phone Number
- Age
- Gender
- Pass Type
- City
- Terms and Conditions

### 🎟️ Pass Options

The project includes the following event pass options:

| Pass Type | Price |
|-----------|-------|
| Student Entry | ₹300 |
| Normal Entry | ₹500 |
| VIP Pass | ₹1500 |

### 👕 Jersey Page

The jersey page allows users to browse available cricket jerseys.

Features include:

- Jersey search
- Jersey filtering
- Team jersey cards
- Size selection
- Sizes from S to XXL
- Buy Now option
